# Индекс общих знаний

Здесь будут долговременные продуктовые понятия, правила и принятые решения, общие для монорепозитория. Сейчас содержательных концептов ещё нет; исходное видение записано в [README](../README.md). Не считайте его готовой спецификацией первой версии.

Перед решением определите область ответственности задачи. Прочитайте только подходящие документы из этого индекса и локального индекса подпроекта, если он есть, затем их актуальный текст целиком. Путь или запись «прочитано» не заменяет содержимое. После смены области или переноса сессии восстановите недостающий текст; неизменившееся в текущем контексте повторно не читайте.

Новые знания добавляйте сюда только когда они применяются несколькими подпроектами. Знания одного подпроекта держите рядом с ним и добавляйте ссылку в его индекс. Продуктовый контракт поведения принадлежит спецификации в `workflow/specs/`, а процесс работы — `workflow/`; не создавайте параллельный источник правила здесь.
