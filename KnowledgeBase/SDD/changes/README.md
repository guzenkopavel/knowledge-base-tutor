# Открытые SDD-изменения

Один каталог `<имя>/` содержит `spec.md`, необязательный `design.md`, `tasks.md` и нужные снимки в `inputs/`. Выберите общий или локальный SDD-корень по [карте](../README.md). Процесс — в [`workflow/sdd.md`](../../../workflow/sdd.md), шаблоны — в [`workflow/templates/`](../../../workflow/templates/). Для `fast` change не создаётся. После явной приёмки и переноса требований каталог перемещается в `archive/<дата>-<имя>/`.
