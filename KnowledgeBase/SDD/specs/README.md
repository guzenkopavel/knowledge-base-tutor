# Основные спецификации

Принятый контракт каждой области хранится в `specs/<область>/spec.md` внутри SDD-корня владельца. Файл создаётся при архивировании первого принятого изменения или по явной задаче описать существующий контракт. Один `REQ-*` принадлежит одному основному документу. Выбор общего или локального корня — в [карте SDD](../README.md), правила актуальности — в [`workflow/spec-maintenance.md`](../../../workflow/spec-maintenance.md).
