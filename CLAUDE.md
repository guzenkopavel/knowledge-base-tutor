# Инструкции для Claude

Общие правила репозитория находятся в [`AGENTS.md`](AGENTS.md). Общая база знаний расположена в `KnowledgeBase/`, а процессы и скиллы — в `workflow/`.

При работе с конкретным подпроектом также учитывайте его локальные инструкции, если они есть.

Для изменения самого харнеса используйте [Harness Change](workflow/skills/harness-change/SKILL.md), а для его проверки — [Harness Review](workflow/skills/harness-review/SKILL.md). Оба скилла хранятся в `workflow/skills/`; их список приведён в [`workflow/README.md`](workflow/README.md).
