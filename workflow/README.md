# Workflow

Здесь находятся общие для монорепозитория процессы и скиллы. Инструкции, относящиеся только к одному будущему подпроекту, размещаются внутри этого подпроекта.

## Скиллы

- [Harness Change](skills/harness-change/SKILL.md) — изменить инструкции, скиллы или другой процесс работы с репозиторием.
- [Harness Review](skills/harness-review/SKILL.md) — проверить эти материалы на согласованность и пригодность к использованию.

Скиллы описывают цель и основные шаги работы. Они не требуют специальных ролей, линтеров или скриптов, пока такие инструменты не появятся в репозитории.

Codex обнаруживает скиллы через `.agents/skills/`, Claude Code — через `.claude/skills/`. Оба каталога содержат относительные ссылки на основные папки в `workflow/skills/`; изменения вносятся в них. При добавлении скилла используйте [Harness Change](skills/harness-change/SKILL.md), чтобы создать обе ссылки в том же изменении.
