# Открытые изменения

Один каталог `<имя>/` содержит `spec.md`, необязательный `design.md`, `tasks.md` и нужные снимки источников в `inputs/`. Начинайте с [ядра SDD](../sdd.md) и шаблонов в `../templates/`. Не создавайте каталог ради ограниченной задачи `fast`. Принятое закрытое изменение перемещается в `archive/<дата>-<имя>/`.
