# Harness Review

Этот скилл проверяет, можно ли последовательно пользоваться инструкциями репозитория. Область проверки может охватывать весь харнес или только изменённые файлы.

1. **Собрать контекст.** Прочитать относящиеся к области `AGENTS.md`, `CLAUDE.md`, `workflow/` и, если есть, локальные инструкции подпроекта. Выяснить, какой файл служит основным источником каждого правила.
2. **Проверить механическое.** Убедиться, что ссылки ведут к существующим файлам, упомянутые скиллы и инструменты действительно доступны, а `SKILL.md` содержит корректные `name` и `description`.
3. **Проверить смысл.** Найти противоречия, дубли правил, расхождение общих и локальных инструкций, неясные условия применения скиллов и требования к ещё не существующей инфраструктуре.
4. **Передать результат.** Для каждой существенной находки указать место, влияние и конкретное исправление. Если задача включает исправление, внести его и проверить затронутые места ещё раз; при запросе только на ревью оставить файлы без изменений.

Для проверки достаточно доступных в репозитории средств. Отдельный линтер или набор ролей не является обязательным условием ревью.
