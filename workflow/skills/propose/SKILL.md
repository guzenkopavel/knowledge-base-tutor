# Propose

Прочитайте [ядро SDD](../../sdd.md), [планирование](../../sdd-planning.md) и только относящиеся знания по [индексу](../../../KnowledgeBase/index.md). Найдите действующий контракт по [правилам спецификаций](../../spec-maintenance.md).

Создайте или продолжите `workflow/changes/<имя>/spec.md` по [шаблону](../../templates/change-spec.md): сохраните источник, актуальные `USR-*`, согласованные изменения, границы, дельту `REQ-*` и наблюдаемую приёмку. Уточните только неразрешённый продуктовый выбор. `Status: accepted` ставьте после его согласования; если пользователь уже разрешил следующий этап, продолжайте без повторного вопроса.
