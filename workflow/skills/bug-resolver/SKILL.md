# Bug Resolver

Прочитайте [Bug Resolver](../../bug-resolver.md), действующие требования по [правилам](../../spec-maintenance.md) и относящиеся знания через [индекс](../../../KnowledgeBase/index.md). Зафиксируйте наблюдение и ожидаемое поведение, проследите причинную цепочку, проверьте различающие гипотезы. Для короткого расследования достаточно ответа; для продолжения сохраните один временный bug-файл.

После вердикта перейдите в ограниченный `fast`, лёгкий bug-план или [SDD](../../sdd.md) по фактическому масштабу и разрешению. Назовите недоказанные переходы и блокеры; не объявляйте поддержанную гипотезу доказанной причиной.
