# Plan

Прочитайте [ядро SDD](../../sdd.md) и [планирование](../../sdd-planning.md). Выберите явно названный change либо единственный подходящий, не по времени файла. Если `spec.md` ещё не принят, сначала выполните этап [Propose](../propose/SKILL.md).

Прочитайте относящиеся знания и существующую реализацию до существенного технического выбора. Создайте `design.md` лишь когда выбор нужен для совместимости с контрактом. Создайте `tasks.md` как единственный план: сохраните профиль, охват, уровень доказательств, задачи, зависимости, знания, границы и обязательную итоговую сверку. Проверьте готовность по [сверке плана](../../plan-review.md). Если дальнейшая реализация уже разрешена пользователем, переходите к ней.
