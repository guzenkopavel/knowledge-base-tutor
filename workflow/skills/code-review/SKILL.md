# Code Review

Прочитайте [Code Review](../../code-review.md). Определите явную цель и точную версию либо примените описанный там порядок выбора. Найдите действующий контракт и относящиеся знания, затем проверьте реальные причинные риски и контрдоказательства.

Верните только подтверждённые замечания с местом, условием и последствием, отдельно вопросы и ограничения. Для короткого ревью не создавайте state. В итоговой задаче SDD или bug-плана используйте метод ревью в существующем артефакте, без второго процесса. Исправление и исполняемые проверки выполняются отдельно по разрешённому маршруту.
