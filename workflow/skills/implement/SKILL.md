# Implement

Прочитайте [ядро SDD](../../sdd.md) и раздел [Исполнение](../../sdd-execution.md#исполнение). Выберите указанную задачу или следующий готовый шаг активного плана. Восстановите принятый контракт, зависимости, выбранные знания и актуальные результаты. Если подготовка отсутствует, завершите её по [Plan](../plan/SKILL.md) в пределах разрешения пользователя.

Исполняйте сохранённый профиль и охват. После задачи сопоставьте фактический diff с требованиями и запишите `Completion` с доказательствами и ограничениями. Для последней задачи дополнительно прочитайте [Закрытие](../../sdd-execution.md#закрытие), выполните итоговую сверку и при готовности поставьте `awaiting_acceptance`. Не архивируйте результат без явной приёмки.
