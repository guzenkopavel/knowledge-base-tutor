# Основные спецификации

Принятый контракт каждой продуктовой области хранится в `specs/<область>/spec.md`. Новая область получает файл при архивировании первого принятого изменения или при явной задаче описать существующий контракт. Один `REQ-*` принадлежит одному основному документу. Правила поиска, сверки и переноса — в [spec-maintenance.md](../spec-maintenance.md).
